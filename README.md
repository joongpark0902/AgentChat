# AgentChat — AI 3명 단톡방

AI 3명이 iMessage 단톡방처럼 대화하며 작업하고 서로 검증하는 로컬 멀티에이전트 시스템입니다.
API 키는 쓰지 않고 **이미 로그인된 공식 CLI만** subprocess로 부릅니다(구독 토큰 추출 없음).
터미널을 열 필요 없이 **브라우저 대화창 안에서 대화·설정·파일 확인·승인을 모두** 처리합니다.

| 참여자 | 역할 | 엔진 | 권한 |
|---|---|---|---|
| Jake | 실무자: 작업 수행, 코드·문서 작성 | `claude -p` (모델 미지정 = 요금제 기본 모델) | **auto 모드**: 대부분 분류기가 자동 판단. **삭제·이동·이름변경·git push/rm/clean/reset --hard 는 항상 채팅창 승인**. 작업 폴더 밖 쓰기는 분류기가 판단(자동 허용될 수 있음) |
| Clara | 결과물 검수: **결과물 파일을 직접 열어** 지시 항목별 충족·결과물 상태·양식·서술·사용자 결정 사항 확인 | `claude -p` (모델 미지정 = 요금제 기본 모델) | 읽기 + `python` 실행(결과물 열기용). 수정 도구(Edit) 없음, 쓰기는 `_qa\`만 묻지 않음. python 이 아닌 명령은 승인 카드 |
| Eric | 숫자 검증: 직접 실행·재계산, 수식 연계, 회사 자료 출처 추적, **외부 자료 원문 검증**(웹 검색·MCP), 경계·예외 | `codex exec` (Codex 기본 모델) | 작업 폴더 쓰기(테스트 실행용). 소스 수정은 지침으로 금지 |

프로필 사진은 Codex 내장 이미지 생성(ChatGPT 구독)으로 만든 **가상 인물** 사진입니다.

## 처음 설치 (Windows 전용)

1. 준비물: Windows 10/11, [Python 3.10+](https://www.python.org/downloads/), 로그인된 [Claude Code](https://claude.com/claude-code)(`claude auth status`), 선택으로 Codex(ChatGPT 로그인, `codex login status`)
2. 이 저장소를 받습니다: `git clone https://github.com/joongpark0902/AgentChat.git` 또는 초록색 **Code → Download ZIP** 후 압축 풀기
3. **`실행.bat` 더블클릭** — python 을 스스로 찾고, 처음 한 번 필요한 패키지를 설치한 뒤 브라우저로 엽니다
4. 처음 실행하면 `config\agents.example.yaml`·`settings.example.yaml`이 `agents.yaml`·`settings.yaml`(개인 설정, git 제외)로 복사됩니다. 이후 설정은 화면의 ⚙에서 바꿉니다
5. 자기 환경에 맞추기
   - **모델**: 기본은 모델 미지정(각자 요금제의 CLI 기본 모델). 헤더의 사진을 눌러 담당자별로 고릅니다. Claude Pro 는 한도가 낮으니 Sonnet, Max 는 Opus 를 권합니다(3명이 각자 세션을 돌려 사용량이 빠르게 듭니다)
   - **Codex 가 없으면**: 새 대화 창이나 대화 `⋯` 메뉴에서 Eric 을 빼면 Jake·Clara 만으로 돕니다. 빼지 않아도 Eric 만 "검토 실패"로 표시되고 과제는 진행됩니다
   - **체크리스트**: 회계·감사 업무용 예시입니다. ⚙ → 담당자 → 체크리스트를 자기 업무에 맞게 바꾸세요
   - **호칭**: ⚙ → 기본 → 내 호칭
- Mac·Linux 는 지원하지 않습니다(프로세스 종료·파일 열기·실행 파일이 Windows 기준).

## 실행

1. 준비(최초 1회)
   - `claude auth status` 결과가 `loggedIn: true`인지 확인
   - Codex 앱에 ChatGPT로 로그인되어 있는지 확인
   - 패키지 설치: `python -m pip install -r requirements.txt`
2. **`작업방` 바로가기(초록 말풍선 아이콘) 더블클릭** → 브라우저가 http://127.0.0.1:8780 으로 열립니다. 작업표시줄 고정 가능. (`실행.bat` 또는 `python -m app.server` 도 같음)
3. 왼쪽 위 ✎ → 새 대화 → 입력창에 지시 → Enter (줄바꿈 Shift+Enter)

## `/` 명령 · 메모리

- 메시지를 `/`로 시작하면 **감싸지 않고 그대로** Claude 담당자(기본 Jake, `@Clara /명령`처럼 지정 가능)에게 보내고 검토 없이 실행합니다.
  입력창에 `/`만 치면 쓸 수 있는 명령·스킬 목록이 뜹니다(목록은 Claude 담당자가 한 번 답한 뒤 채워짐).
- `-p` 모드에서 실측한 결과: `/footing`·`/codex` 같은 스킬과 `/compact`·`/context`·`/usage` 등 약 90개는 됩니다.
  `/rc`(원격 제어)는 "isn't available in this environment"로 안 되고, `/resume`은 목록에 없습니다. 앱에서는 대화마다 세션이 이어지므로 `/resume`이 필요 없습니다.
- Eric(Codex)은 `/` 명령을 쓸 수 없고, 진행 중에는 `/` 명령을 받지 않습니다.
- **메모리**: Claude Code는 작업 폴더마다 메모리를 따로 둡니다. 그래서 역할 지침에 **터미널과 같은 메모리 폴더**(`settings.yaml`의 `memory_dir`, 기본 `~/.claude/projects/<홈>/memory`)를 쓰라고 적어 두었습니다.
- 빠른 질문·`@이름`으로 부를 때는 최근 대화 8개를 참고용으로 함께 넘깁니다. 그래서 세션에 없는 앞 맥락도 압니다.

## 대화 흐름 (검토 모드)

```
지시 → Jake 작업·보고 → Clara·Eric 동시에 검토(Eric은 실행·재계산·원문 확인)
   ├─ 둘 다 승인(APPROVE) → 완료
   ├─ 지적 있음 → 지적을 모아 Jake에게 → 수정 → 다시 검토 (라운드 +1)
   └─ 최대 라운드(기본 3) 후에도 합의 안 됨 → 마지막 지적 원문을 모아 사용자에게 넘김
```

- **사용자 결정 지적(v8)**: 필수 지적마다 `needs_user`를 붙입니다. 실무자가 고칠 수 없는 사안이거나, 실무자가 근거를 들어 "수정 안 함"으로 답한 것을 다시 올리는 지적이면 true 입니다. 남은 필수 지적이 전부 true 면 라운드를 더 돌지 않고 바로 사용자에게 넘깁니다(9/30 실측: 사용자가 정할 '숨김 열' 한 건으로 두 과제가 3라운드까지 헛돌았음).
- **파일을 열지 않은 승인은 무효(v8)**: 바뀐 파일이 있는데 감독이 도구를 한 번도 쓰지 않고 승인하면 한 번 되돌려 보내고, 그래도 같으면 그 판정을 빼고 진행합니다(9/30 실측: Clara 가 Read 로는 xlsx·pptx 를 못 열어 보고문만 읽고 7회 연속 승인). Clara 는 `python tools\dump_office.py <파일>`로 pptx·xlsx·docx 의 글자·표·수식·병합·숨김 행·열을 봅니다.
- **라운드 2부터**는 감독에게 "직전 지적의 해결 여부와 바뀐 파일만 확인"하라고 알립니다.
- **판정**: 감독은 `{verdict, summary, issues[{severity, description, needs_user}], requirements[{item, met, evidence}], checks}` JSON으로 답합니다(Claude `--json-schema`, Codex `--output-schema`). `필수`(blocker)가 하나라도 있으면 수정 요청이고, `제안`(minor)만 있으면 승인입니다. JSON을 못 읽으면 수정 요청으로 처리하고 경고를 표시합니다.
- **지적 중복 방지**: 감독마다 체크리스트와 "담당 외"를 따로 줍니다. 두 감독 모두 "문제가 없으면 없다고 말하라"는 지침을 받습니다.
- **끼어들기**: 진행 중에 보낸 메시지는 **다음 에이전트 호출 직전**에 끼워 넣습니다. 실무자가 아직 못 받은 지시는 감독에게 "누락으로 지적하지 말 것"으로 표시하고, 승인이 나도 한 라운드 더 돌아 반영합니다.
- **세션 유지**: Claude는 `--session-id` → `--resume`, Codex는 `exec` → `exec resume <thread_id>`. 세션 ID는 `logs\<대화ID>.state.json`에 저장돼 서버를 재시작해도 이어집니다.

## 설정 파일

화면의 ⚙설정에서 바꾸는 것이 기본입니다. 저장할 때마다 이전 파일을 `config\backups\backup_<시각>_설정변경_*.yaml`로 백업합니다.
- `config\agents.yaml`: 참여자, 순서(`worker`, `reviewers`), 호칭(`user.name`)
- `config\settings.yaml`: 포트, 최대 라운드, 제한 시간, CLI 경로, 샌드박스, `claude.safe_mode`(= 전역 규칙 OFF 기본값)
- 이름·사진은 저장 즉시 반영됩니다. 역할 지침·전역 규칙은 **새 대화부터** 확실히 적용됩니다(Claude가 세션의 시스템 프롬프트를 첫 호출 때 고정하기 때문).

## 속도·외부 자료 (2026-09-28 실측)

- 감독 두 명은 **동시에** 검토합니다. 차례로 하던 때는 한 라운드가 최대 17분이었습니다. 한 명이 멈추거나 제한 시간에 걸려도 과제를 멈추지 않고, 나머지 감독의 판정으로 진행합니다.
- 답하는 동안 입력 중 표시에 **중간 메모(💬), 지금 하는 일, 지금까지 쓴 토큰**이 실시간으로 뜨고, 왼쪽 아래 한도 게이지도 답변 도중에 갱신됩니다.
  Claude는 CLI 이벤트, Codex는 세션 파일을 4초마다 읽습니다.
- 외부 자료: Eric(Codex)은 웹 검색이 됩니다. MCP는 `approvals_reviewer="auto_review"`로 호출합니다(없으면 "requires approval, but approval policy is never"로 거절됨).
  Jake·Clara는 DART·verifier MCP가 됩니다. Clara는 조회용 MCP(DART·moleg·verifier)를 묻지 않고 씁니다.

## 폰에서 쓰기 (v7, 2026-09-29)

인터넷에 공개하지 않고 **Tailscale**(내 기기끼리만 연결되는 사설망)로만 들어옵니다.

- 서버는 두 포트를 **이 PC 안(127.0.0.1)에서만** 엽니다.
  - `8780`: PC 화면. 지금처럼 로그인 없음.
  - `8790`: 폰 전용. **항상 로그인**해야 합니다. Tailscale serve 가 폰 요청을 여기로 넘깁니다.
  - 프록시를 거치면 폰 요청도 127.0.0.1 에서 온 것으로 보여서, 주소가 아니라 **포트로** 폰과 PC 를 구분합니다.
- **처음 한 번 설정**
  1. PC·아이폰에 Tailscale 설치 → 같은 계정으로 로그인
  2. Tailscale 관리 화면(DNS)에서 MagicDNS 와 HTTPS Certificates 켜기
  3. PC 에서 `tailscale serve --bg 8790` (https://<PC이름>.<tailnet>.ts.net → 127.0.0.1:8790)
     공개 인터넷용인 `tailscale funnel` 은 쓰지 않습니다(`tailscale funnel status` 로 꺼져 있는지 확인).
  4. PC 작업방 → 설정 → **모바일·알림**에서 비밀번호(8자 이상) 정하기
  5. 아이폰 Safari 로 위 주소 열기 → 로그인 → 공유 → **홈 화면에 추가** → 그 아이콘으로 열기
  6. 설정 → 모바일·알림 → **이 기기에서 알림 받기** → 시험 알림
- **로그인**: 비밀번호는 PBKDF2 해시로만 저장(`private\auth.json`). 세션 쿠키는 30일, HttpOnly·Secure·SameSite=Strict. 5번 틀리면 5분 잠금. "모든 기기 로그아웃"·비밀번호 변경 시 기존 로그인 모두 끊김. 비밀번호는 PC 화면에서만 바꿀 수 있습니다.
- **PC 포트 보안**: 다른 웹사이트가 `127.0.0.1:8780` 작업방에 몰래 지시를 보내지 못하게, Origin 이 화면 주소와 다른 POST·WebSocket 은 거절합니다(403 / 4403).
- **폰에서 막은 것**: PC 화면에 창이 뜨는 기능(폴더 선택 창, 엑셀 등으로 열기, 탐색기 열기). 파일은 미리보기와 "원본 파일 열기·저장"으로 봅니다.
- **화면(폭 860px 이하)**: 대화 목록 = 왼쪽 서랍(☰), 파일 = 오른쪽 서랍, 모델 = 아래에서 올라오는 시트, 입력창 = 아래 고정(아이폰 키보드에 맞춰 화면 높이를 visualViewport 로 조정).
- **알림(웹 푸시)**: 라운드 완료 · 3라운드 초과(판단 필요) · 오류로 멈춤 · 빠른 질문 답변 · 승인 카드가 뜰 때. 화면을 보고 있는 기기와 직접 중단한 경우는 보내지 않습니다.
  Apple·Google 푸시 서버를 거치므로(내용은 RFC 8291 로 암호화) 문구에 대화 제목·고객사명·작업 내용을 넣지 않습니다("Jake 작업 완료 · 확인해 주세요").
  서명 키·구독 목록은 `private\` 에 있습니다. 아이폰은 iOS 16.4 이상 + 홈 화면에 추가한 앱에서만 알림을 받습니다.
- `private\` 폴더는 비밀번호 해시·키가 있어 git·백업 zip 에 넣지 않습니다.
- PC 가 꺼져 있거나 절전이면 폰에서 들어올 수 없습니다(연결 안 됨 안내 화면).

## 사용량 계산 방식 (2026-09-28 실측)

- 한도: Claude는 호출 때 오는 `rate_limit_event`(5시간·주간 사용률), Codex는 세션 파일 `~/.codex/sessions/.../rollout-*-<thread>.jsonl`의 `rate_limits`를 읽습니다. 각 CLI가 보고한 값 그대로입니다.
- 답변별 토큰: Claude의 `modelUsage`·`total_cost_usd`와 Codex의 `turn.completed.usage`는 **세션 누적값**입니다. 그래서 직전 누적값을 세션 상태에 저장해 두고 **차이로 계산**합니다. 기준점이 없는 예전 세션의 첫 답변은 호출 단위 값을 씁니다(Claude는 금액 없음, Codex는 세션 파일의 마지막 작업 구간).
- 참고 금액은 Claude CLI가 알려주는 API 정가 환산값입니다. 구독이라 실제 청구액이 아닙니다.
- 수정 전에 누적값으로 잘못 기록된 답변은 "세션 누적 · 합계 제외"로 표시하고 합계에서 뺍니다.

## 알아둘 점 (2026-09-28 실측)

- **전역 규칙 ON**이면 `claude -p` 첫 호출 입력이 약 69k 토큰입니다(사용자 전역 규칙·플러그인·훅 포함). OFF는 `--safe-mode`이며, 로그인·모델 선택은 정상 동작함을 확인했습니다.
- Codex `config.toml`의 `[windows] sandbox = "elevated"` 상태에서는 샌드박스가 AppData의 Python에 접근하지 못해, 호출할 때만 `-c windows.sandbox="unelevated"`로 바꿉니다(파일은 수정하지 않음).
- Codex CLI는 PATH에 없어 `%LOCALAPPDATA%\OpenAI\Codex\bin\*\codex.exe` 중 최신을 자동으로 찾습니다.
- 승인은 Claude의 `--permission-prompt-tool stdio` 방식입니다: CLI가 `control_request(can_use_tool)`을 보내면 화면에 카드를 띄우고, 누른 결과를 `control_response`로 돌려줍니다.
- 기존 프로젝트 폴더에서 작업하면 그 폴더의 CLAUDE.md/AGENTS.md도 읽힙니다(전역 규칙 ON일 때). Eric의 검증용 임시 파일은 `<작업 폴더>\_qa\`에 생길 수 있습니다.
